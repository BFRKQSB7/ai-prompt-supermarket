# AI 绘画提示词超市

本地离线的 AI 绘画提示词生成工具：**点选中文标签，自动生成英文提示词**。单文件、零依赖、双击即用。

## 特性

- **全量标签库**：内置 32 万+ Danbooru 中英对照标签（含角色 / 画师 / 版权 / 作品分类），每日更新数据源
- **分类 + 二级分类**：发色 / 发型 / 眼睛 / 表情 / 身材 / 服装 / 姿势 / 场景 / 画风 / NSFW 等，大类可继续细分（如服装 → 上衣 / 裙装 / 内衣 / 鞋配饰）
- **全局搜索**：中文、英文、下划线、空格都能搜，覆盖全库
- **收藏**：★ 收藏常用词，支持「仅看收藏」筛选，跨会话持久化
- **全部浏览**：一键查看最常用 1000 条
- **负面提示词**：内置负面词分类，自动分流到负面框
- 下划线自动转空格输出（`long_hair` → `long hair`），贴进工作流即用

## 用法

双击打开 `index.html`，点选分类中的中文标签，顶部的提示词栏会自动拼好英文提示词，一键复制正面 / 负面。
